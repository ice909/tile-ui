> Use ToggleGroup for single or multiple toolbar choices with roving focus.

<ComponentDemo slug="toggle-group" />

## Registry install

```bash
pnpm dlx shadcn@latest add @tile-ui/toggle-group
```

## Package usage

```tsx
import { ToggleGroup, ToggleGroupItem } from '@tile-ui/solid';

<ToggleGroup type="single" defaultValue="a">
	<ToggleGroupItem value="a">A</ToggleGroupItem>
	<ToggleGroupItem value="b">B</ToggleGroupItem>
</ToggleGroup>
```

## Highlights

- Single and multiple modes
- Item variants and sizes

## API reference

| Prop            | Type                                | Default |
| --------------- | ----------------------------------- | ------- |

| `value`         | `ToggleGroupValue`                  | —       |

| `onValueChange` | `(value: ToggleGroupValue) => void` | —       |
| `disabled`      | `boolean`                           | —       |
| `orientation`   | `RadioGroupOrientation`             | —       |
