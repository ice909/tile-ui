> Use Accordion to organize related disclosure sections with predictable keyboard movement.

<ComponentDemo slug="accordion" />

## Registry install

```bash
pnpm dlx shadcn@latest add @tile-ui/accordion
```

## Package usage

```tsx
import { Accordion, AccordionItem, AccordionTrigger, AccordionContent } from '@tile-ui/solid';

<Accordion type="single" defaultValue="one" collapsible>
	<AccordionItem value="one">
		<AccordionTrigger>Section one</AccordionTrigger>
		<AccordionContent>Content one.</AccordionContent>
	</AccordionItem>
</Accordion>
```

## Highlights

- Single and multiple disclosure modes
- Disabled-aware roving focus
- Stable custom or generated trigger/content IDs

## API reference

### Accordion

| Prop            | Type                                  | Default |
| --------------- | ------------------------------------- | ------- |
| `type`          | `'single' \| 'multiple'`              | —       |
| `value`         | `string \| string[]`                  | —       |
| `defaultValue`  | `string \| string[]`                  | —       |
| `onValueChange` | `(value: string \| string[]) => void` | —       |
| `collapsible`   | `boolean`                             | —       |
| `ref`           | `AccordionRef<HTMLDivElement>`        | —       |
