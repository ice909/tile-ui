<ComponentDemo slug="badge" />

## Registry install

```bash
pnpm dlx shadcn@latest add @tile-ui/badge
```

## Package usage

```tsx
import { Badge } from '@tile-ui/solid';

<Badge variant="secondary">New</Badge>
```

## Highlights

- Six visual variants
- Native Solid span attributes
- Pairs with Card and status surfaces
