<ComponentDemo slug="label" />

## Registry install

```bash
pnpm dlx shadcn@latest add @tile-ui/label
```

## Package usage

```tsx
import { Label, Input } from '@tile-ui/solid';

<Label for="email" required>Email</Label>
<Input id="email" type="email" />
```

## Highlights

- Required indicator
- Pairs with native and custom fields
