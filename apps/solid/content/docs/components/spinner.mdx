<ComponentDemo slug="spinner" />

## Registry install

```bash
pnpm dlx shadcn@latest add @tile-ui/spinner
```

## Package usage

```tsx
import { Spinner } from '@tile-ui/solid';

<Spinner />
```

## Highlights

- Three sizes
- Pulse animation

| Item      | Purpose                            |
