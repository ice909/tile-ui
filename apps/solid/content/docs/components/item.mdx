> Use Item for compact media, content, and action rows.

<ComponentDemo slug="item" />

## Registry install

```bash
pnpm dlx shadcn@latest add @tile-ui/item
```

## Package usage

```tsx
import { Item, ItemContent, ItemTitle } from '@tile-ui/solid';

<Item variant="outline">
	<ItemContent><ItemTitle>Solid registry</ItemTitle></ItemContent>
</Item>
```

## Highlights

- Media, content, and action regions
- Native div root
- Outline and muted variants

## Registry dependencies

| Item     | Purpose                            |
| -------- | ---------------------------------- |
| `item`   | Component source and module styles |
| `core`   | Framework-agnostic logic helpers   |
| `styles` | Shared SCSS tokens and globals     |
