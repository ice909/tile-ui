> Use Message primitives to compose semantic conversation rows without adding state management.

<ComponentDemo slug="message" />

## Registry install

```bash
pnpm dlx shadcn@latest add @tile-ui/message
```

## Package usage

```tsx
import { MessageGroup, Message, MessageContent, MessageFooter } from '@tile-ui/solid';

<MessageGroup>
	<Message align="end">
		<MessageContent>Registry complete.</MessageContent>
		<MessageFooter>Now</MessageFooter>
	</Message>
</MessageGroup>
```

## Highlights

- Start and end alignment
- Avatar, header, content, and footer primitives
- Native static message markup
