> Use Table primitives for semantic tabular data with horizontal overflow support.

<ComponentDemo slug="table" />

## Registry install

```bash
pnpm dlx shadcn@latest add @tile-ui/table
```

## Package usage

```tsx
import { Table, TableHeader, TableRow, TableHead, TableBody, TableCell } from '@tile-ui/solid';

<Table>
	<TableHeader>
		<TableRow>
			<TableHead>Name</TableHead>
		</TableRow>
	</TableHeader>
	<TableBody>
		<TableRow>
			<TableCell>Tile UI</TableCell>
		</TableRow>
	</TableBody>
</Table>
```

## Highlights

- Header, body, footer, and caption
- Row, head, and cell primitives
- Pairs with Pagination
