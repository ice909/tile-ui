> Use ButtonGroup to keep related native actions visually and semantically adjacent.

<ComponentDemo slug="button-group" />

## Registry install

```bash
pnpm dlx shadcn@latest add @tile-ui/button-group
```

## Package usage

```tsx
import { ButtonGroup, Button } from '@tile-ui/solid';

<ButtonGroup>
	<Button>One</Button>
	<Button>Two</Button>
	<Button>Three</Button>
</ButtonGroup>
```

## Highlights

- Horizontal and vertical orientation
- Text and separator
