> Use Marker to annotate or divide supporting content.

<ComponentDemo slug="marker" />

## Registry install

```bash
pnpm dlx shadcn@latest add @tile-ui/marker
```

## Package usage

```tsx
import { Marker, MarkerIcon, MarkerContent } from '@tile-ui/solid';

<Marker variant="separator">
	<MarkerIcon />
	<MarkerContent>Status</MarkerContent>
</Marker>
```

## Highlights

- Default, separator, and border variants
- Native div root
- Optional icon primitive

## Registry dependencies

| Item     | Purpose                            |
| -------- | ---------------------------------- |
| `marker` | Component source and module styles |
