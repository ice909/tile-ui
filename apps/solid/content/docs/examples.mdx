The 61 component pages are the example gallery for the Solid registry. Every preview is rendered from `apps/solid/components/demos/<slug>.tsx`, and the displayed source is generated by reading that exact file.

## Interactive examples

- [Toggle](/docs/components/toggle) updates fine-grained local state after hydration.
- [Dialog](/docs/components/dialog) portals content, manages focus, closes on Escape, and restores focus.
- [Input](/docs/components/input) demonstrates accessible labels, helper text, and validation messaging.
- [Attachment](/docs/components/attachment) proves action isolation from card preview behavior.
- [Avatar](/docs/components/avatar) demonstrates deterministic image load and fallback transitions.
- [Aspect Ratio](/docs/components/aspect-ratio) preserves constrained responsive geometry across SSR and hydration.
- [Accordion](/docs/components/accordion) and [Tabs](/docs/components/tabs) demonstrate disabled-aware keyboard navigation and stable IDs.
- [Calendar](/docs/components/calendar) pins its SSR clock and initial month while exposing date-grid navigation.
- [Message Scroller](/docs/components/message-scroller) demonstrates observed scrolling, controls, and remount behavior.

## Composed surfaces

- [Card](/docs/components/card) combines content and actions.
- [Button](/docs/components/button), [Badge](/docs/components/badge), and [Separator](/docs/components/separator) demonstrate the shared visual language.

## Source guarantee

There are no separately maintained display snippets. `docs:build` derives highlighted preview source from the demo files before the SolidStart production build.
