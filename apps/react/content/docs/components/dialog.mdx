## Registry install

```bash
pnpm dlx shadcn@latest add @tile-ui/dialog
```

## Package usage

```tsx
import { Dialog, DialogTrigger, DialogContent, DialogHeader, DialogTitle, DialogDescription, DialogFooter, Button } from '@tile-ui/react';

<Dialog>
	<DialogTrigger>Open</DialogTrigger>
	<DialogContent>
		<DialogHeader>
			<DialogTitle>Edit profile</DialogTitle>
			<DialogDescription>Make changes to your profile.</DialogDescription>
		</DialogHeader>
		<DialogFooter>
			<Button>Save</Button>
		</DialogFooter>
	</DialogContent>
</Dialog>
```

## Highlights

- Trigger, overlay, and content
- Header, footer, title, and description
- Close button
