> Use HoverCard to show a preview when hovering a trigger.

<ComponentDemo slug="hover-card" />

## Registry install

```bash
pnpm dlx shadcn@latest add @tile-ui/hover-card
```

## Package usage

```tsx
import { HoverCard, HoverCardTrigger, HoverCardContent } from '@tile-ui/react';

<HoverCard>
	<HoverCardTrigger>Hover me</HoverCardTrigger>
	<HoverCardContent>Preview content.</HoverCardContent>
</HoverCard>
```

## Highlights

- Open and close delay
- Side and align
- Trigger and content

## API reference

### HoverCard

| Prop           | Type                      | Default |
| -------------- | ------------------------- | ------- |
| `open`         | `boolean`                 | —       |
| `defaultOpen`  | `boolean`                 | —       |
| `openDelay`    | `number`                  | —       |
| `closeDelay`   | `number`                  | —       |
| `onOpenChange` | `(open: boolean) => void` | —       |

### HoverCardTrigger

| Prop      | Type      | Default |
| --------- | --------- | ------- |

### HoverCardContent

| Prop         | Type                                     | Default |
| ------------ | ---------------------------------------- | ------- |
