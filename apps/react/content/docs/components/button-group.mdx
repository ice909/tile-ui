> Use ButtonGroup to attach related buttons into a single control.

<ComponentDemo slug="button-group" />

## Registry install

```bash
pnpm dlx shadcn@latest add @tile-ui/button-group
```

## Package usage

```tsx
import { ButtonGroup } from '@tile-ui/react';

<ButtonGroup>
	<Button>One</Button>
	<Button>Two</Button>
	<Button>Three</Button>
</ButtonGroup>
```

## Highlights

- Horizontal and vertical orientation
- Text and separator
