> Use Sheet to slide a panel from the edge of the screen.

<ComponentDemo slug="sheet" />

## Registry install

```bash
pnpm dlx shadcn@latest add @tile-ui/sheet
```

## Package usage

```tsx
import { Sheet } from '@tile-ui/react';

<Sheet>
	<SheetTrigger>Open</SheetTrigger>
	<SheetContent side="right">
		<SheetTitle>Details</SheetTitle>
		<SheetDescription>Supporting details.</SheetDescription>
	</SheetContent>
</Sheet>
```

## Highlights

- Four sides
- Trigger, overlay, and content
- Header, footer, title, and description
