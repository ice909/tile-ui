> Use DropdownMenu to offer a list of actions from a trigger.

<ComponentDemo slug="dropdown-menu" />

## Registry install

```bash
pnpm dlx shadcn@latest add @tile-ui/dropdown-menu
```

## Package usage

```tsx
import { DropdownMenu } from '@tile-ui/react';

<DropdownMenu>
	<DropdownMenuTrigger>Menu</DropdownMenuTrigger>
	<DropdownMenuContent>
		<DropdownMenuItem>Profile</DropdownMenuItem>
		<DropdownMenuItem>Settings</DropdownMenuItem>
	</DropdownMenuContent>
</DropdownMenu>
```

## Highlights

- Item, checkbox item, and radio group
- Sub menus
- Side, align, and offset
