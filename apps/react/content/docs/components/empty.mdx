> Use Empty to guide users when there is nothing to display.

<ComponentDemo slug="empty" />

## Registry install

```bash
pnpm dlx shadcn@latest add @tile-ui/empty
```

## Package usage

```tsx
import { Empty } from '@tile-ui/react';

<Empty>
	<EmptyMedia variant="muted">+</EmptyMedia>
	<EmptyTitle>No results</EmptyTitle>
	<EmptyDescription>Try adjusting your search.</EmptyDescription>
</Empty>
```

## Highlights

- Header, media, title, and description
- Default and icon media variants
