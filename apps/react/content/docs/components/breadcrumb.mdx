> Use Breadcrumb to show the current location in a hierarchy.

<ComponentDemo slug="breadcrumb" />

## Registry install

```bash
pnpm dlx shadcn@latest add @tile-ui/breadcrumb
```

## Package usage

```tsx
import { Breadcrumb } from '@tile-ui/react';

<Breadcrumb>
	<BreadcrumbList>
		<BreadcrumbItem>
			<BreadcrumbLink href="/docs">Docs</BreadcrumbLink>
		</BreadcrumbItem>
		<BreadcrumbSeparator />
		<BreadcrumbItem>
			<BreadcrumbPage>Button</BreadcrumbPage>
		</BreadcrumbItem>
	</BreadcrumbList>
</Breadcrumb>
```

## Highlights

- List, item, link, and page
- Separator and ellipsis
- `asChild` on links
