> Use Marker to tag content with a colored status.

<ComponentDemo slug="marker" />

## Registry install

```bash
pnpm dlx shadcn@latest add @tile-ui/marker
```

## Package usage

```tsx
import { Marker } from '@tile-ui/react';

<Marker variant="green">
	<MarkerIcon />
	<MarkerContent>Online</MarkerContent>
</Marker>
```

## Highlights

- Five color variants
- Icon and content
- `asChild` support
