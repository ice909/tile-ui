> Use Accordion to present collapsible sections.

<ComponentDemo slug="accordion" />

## Registry install

```bash
pnpm dlx shadcn@latest add @tile-ui/accordion
```

## Package usage

```tsx
import { Accordion, AccordionItem, AccordionTrigger, AccordionContent } from '@tile-ui/react';

<Accordion type="single" collapsible>
	<AccordionItem value="one">
		<AccordionTrigger>Section one</AccordionTrigger>
		<AccordionContent>Content one.</AccordionContent>
	</AccordionItem>
</Accordion>
```

## Highlights

- Single and multiple modes
- Collapsible mode
- Item and content

## API reference

### Accordion

| Prop            | Type                                  | Default |
| --------------- | ------------------------------------- | ------- |
| `type`          | `'single' \| 'multiple'`              | —       |
| `value`         | `string \| string[]`                  | —       |
| `defaultValue`  | `string \| string[]`                  | —       |
| `onValueChange` | `(value: string \| string[]) => void` | —       |
| `collapsible`   | `boolean`                             | —       |

### AccordionItem

| Prop       | Type      | Default |
| ---------- | --------- | ------- |
| `value`    | `string`  | —       |
| `disabled` | `boolean` | —       |

### AccordionTrigger

No custom props.

### AccordionContent

No custom props.
