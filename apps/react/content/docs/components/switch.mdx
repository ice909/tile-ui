## Registry install

```bash
pnpm dlx shadcn@latest add @tile-ui/switch
```

## Package usage

```tsx
import { Switch } from '@tile-ui/react';

<Switch />
```

## Highlights

- Two sizes
- Accessible switch role
- Pairs with Field and Form
