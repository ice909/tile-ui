title: Hooks
description: Client-side hooks packaged with Tile UI React.
---

Tile UI React ships a compact set of hooks for common client workflows.

| Hook                                                    | Purpose                                                    |
| ------------------------------------------------------- | ---------------------------------------------------------- |
| [useLocalStorage](/docs/hooks/use-local-storage)        | Persist client state into local or session storage.        |
| [useMediaQuery](/docs/hooks/use-media-query)            | Read responsive state and viewport changes.                |
| [useCopyToClipboard](/docs/hooks/use-copy-to-clipboard) | Handle copy interactions, copied state, and timeout reset. |
