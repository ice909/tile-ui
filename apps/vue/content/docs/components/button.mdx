> Use Button for primary actions, inline confirmations, and lightweight toolbar interactions.

## Registry install

```bash
pnpm dlx shadcn@latest add @tile-ui/button
```

## Package usage

```tsx
import { TButton } from '@tile-ui/vue';

export default defineComponent({
	setup() {
		return () => <TButton>Save changes</TButton>;
	},
});
```

Use the `variant` prop to change the visual treatment:

```tsx
<TButton variant="outline">Outline</TButton>
<TButton variant="destructive">Delete</TButton>
```

Use the `loading` prop to disable interaction and show the inline spinner:

```tsx
<TButton loading>Submitting...</TButton>
```

## Highlights

- Six visual variants
- Loading state support
- Eight sizes from `xs` through `icon-lg`
- Fits naturally into slot-based Vue composition

## API reference

### TButton

| Prop       | Type                                                              | Default   | Notes                                              |
| ---------- | ----------------------------------------------------------------- | --------- | -------------------------------------------------- |
| `variant`  | `default \| destructive \| outline \| secondary \| ghost \| link` | `default` | Chooses the button visual treatment.               |
| `size`     | `default \| sm \| lg \| icon`                                     | `default` | Controls height and padding.                       |
| `loading`  | `boolean`                                                         | `false`   | Disables interaction and shows the inline spinner. |
| `disabled` | `boolean`                                                         | `false`   | Disables the button.                               |
| `type`     | `button \| submit \| reset`                                       | `button`  | The native button type.                            |
