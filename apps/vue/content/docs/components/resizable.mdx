> Use ResizablePanelGroup to create adjustable split layouts.

## Registry install

```bash
pnpm dlx shadcn@latest add @tile-ui/resizable
```

## Package usage

```tsx
import { TResizablePanelGroup } from '@tile-ui/vue';

<TResizablePanelGroup direction="horizontal">
	<TResizablePanel>Left</TResizablePanel>
	<TResizableHandle />
	<TResizablePanel>Right</TResizablePanel>
</TResizablePanelGroup>
```

## Highlights

- Horizontal and vertical
- Panel and handle
- Persistent layout id

## Registry dependencies

| Item        | Purpose                            |

## API reference

### ResizablePanelGroup

| Prop        | Type                         | Default      |
| ----------- | ---------------------------- | ------------ |
| `direction` | `'horizontal' \| 'vertical'` | 'horizontal' |
| `id`        | `string`                     | —            |
