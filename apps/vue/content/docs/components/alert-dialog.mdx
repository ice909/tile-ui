> Use AlertDialog to interrupt for confirmation of a destructive or important action.

## Registry install

```bash
pnpm dlx shadcn@latest add @tile-ui/alert-dialog
```

## Package usage

```tsx
import { TAlertDialog } from '@tile-ui/vue';

<TAlertDialog>
	<TAlertDialogTrigger>Delete</TAlertDialogTrigger>
	<TAlertDialogContent>
		<TAlertDialogTitle>Are you sure?</TAlertDialogTitle>
		<TAlertDialogDescription>This action cannot be undone.</TAlertDialogDescription>
		<TAlertDialogCancel>Cancel</TAlertDialogCancel>
		<TAlertDialogAction>Delete</TAlertDialogAction>
	</TAlertDialogContent>
</TAlertDialog>
```

## Highlights

- Action and cancel buttons
- Overlay and content
- Two sizes
