---

> Use Avatar to show user or entity images with a text fallback.

## Registry install

```bash
pnpm dlx shadcn@latest add @tile-ui/avatar
```

## Package usage

```tsx
import { TAvatar, TAvatarImage, TAvatarFallback } from '@tile-ui/vue';

<TAvatar>
	<TAvatarImage alt="Tile UI" src="https://example.com/avatar.png" />
	<TAvatarFallback>TU</TAvatarFallback>
</TAvatar>
```

## Highlights

- Image, fallback, and badge
- Group stacking
- Three sizes
