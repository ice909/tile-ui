> Use Item to build consistent list rows with media, content, and actions.

## Registry install

```bash
pnpm dlx shadcn@latest add @tile-ui/item
```

## Package usage

```tsx
import { TItem } from '@tile-ui/vue';

<TItem>
	<TItemMedia>+</TItemMedia>
	<TItemContent>
		<TItemTitle>Tile UI</TItemTitle>
		<TItemDescription>A cross-framework component library.</TItemDescription>
	</TItemContent>
	<TItemActions>
		<TButton size="sm">Open</TButton>
	</TItemActions>
</TItem>
```

## Highlights

- Media, content, and actions
- Group and separator
- Three variants

## Registry dependencies

| Item     | Purpose                            |
| -------- | ---------------------------------- |
| `item`   | Component source and module styles |
| `core`   | Framework-agnostic logic helpers   |
| `styles` | Shared SCSS tokens and globals     |

## API reference

### Item

| Prop      | Type                                     | Default |
| --------- | ---------------------------------------- | ------- |
| `variant` | `'neutral' \| 'selected' \| 'hoverable'` | —       |
| `asChild` | `boolean`                                | —       |
