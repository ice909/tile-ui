---
title: Direction
description: Direction provider for reading direction.
---

> Use DirectionProvider to set the reading direction for RTL support.

## Registry install

```bash
pnpm dlx shadcn@latest add @tile-ui/direction
```

## Package usage

```tsx
import { TDirectionProvider } from '@tile-ui/vue';

<TDirectionProvider dir="rtl">
	<App />
</TDirectionProvider>
```

## Highlights

- LTR and RTL
- Context-based

## Registry dependencies

| Item        | Purpose                            |
| ----------- | ---------------------------------- |
| `direction` | Component source and module styles |
| `core`      | Framework-agnostic logic helpers   |
| `styles`    | Shared SCSS tokens and globals     |

## API reference

### DirectionProvider

| Prop  | Type             | Default |
| ----- | ---------------- | ------- |
| `dir` | `'ltr' \| 'rtl'` | —       |
