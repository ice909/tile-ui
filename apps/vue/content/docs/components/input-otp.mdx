> Use InputOTP to collect a one-time code across multiple slots.

## Registry install

```bash
pnpm dlx shadcn@latest add @tile-ui/input-otp
```

## Package usage

```tsx
import { TInputOTP } from '@tile-ui/vue';

<TInputOTP maxLength={6} onComplete={(code) => console.log(code)} />
```

## Highlights

- Numeric, alphanumeric, and text modes
- Slots and groups
- Completion callback
