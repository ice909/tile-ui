---

> Use Menubar for a desktop-style application menu.

## Registry install

```bash
pnpm dlx shadcn@latest add @tile-ui/menubar
```

## Package usage

```tsx
import { TMenubar, TMenubarMenu, TMenubarTrigger, TMenubarContent, TMenubarItem } from '@tile-ui/vue';

<TMenubar>
	<TMenubarMenu value="file">
		<TMenubarTrigger>File</TMenubarTrigger>
		<TMenubarContent>
			<TMenubarItem>New</TMenubarItem>
			<TMenubarItem>Open</TMenubarItem>
		</TMenubarContent>
	</TMenubarMenu>
</TMenubar>
```

## Highlights

- Multiple menus
- Trigger and content
- Checkbox and radio items
