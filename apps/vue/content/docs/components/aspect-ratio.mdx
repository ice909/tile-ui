title: AspectRatio
description: A fixed-ratio content container.
---

> Use AspectRatio to keep media or content at a fixed width-to-height ratio.

## Registry install

```bash
pnpm dlx shadcn@latest add @tile-ui/aspect-ratio
```

## Package usage

```tsx
import { TAspectRatio } from '@tile-ui/vue';

<TAspectRatio ratio={16 / 9}>
	<img src="https://example.com/poster.png" alt="Poster" />
</TAspectRatio>
```

## Highlights

- Ratio prop
- Fills its container
