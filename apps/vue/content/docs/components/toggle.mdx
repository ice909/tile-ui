---
title: Toggle
description: A toggle button with pressed state.
---

> Use Toggle to express a binary on/off selection as a button.

## Registry install

```bash
pnpm dlx shadcn@latest add @tile-ui/toggle
```

## Package usage

```tsx
import { TToggle } from '@tile-ui/vue';

<TToggle variant="outline">Bold</TToggle>
```

## Highlights

- Three variants
- Three sizes
- Pressed state

## Registry dependencies

| Item     | Purpose                            |
| -------- | ---------------------------------- |
| `toggle` | Component source and module styles |
| `core`   | Framework-agnostic logic helpers   |
| `styles` | Shared SCSS tokens and globals     |

## API reference

### Toggle

| Prop      | Type                                | Default |
| --------- | ----------------------------------- | ------- |
| `variant` | `'default' \| 'outline' \| 'ghost'` | —       |
| `size`    | `'sm' \| 'default' \| 'lg'`         | —       |
