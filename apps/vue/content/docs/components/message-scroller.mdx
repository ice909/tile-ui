> Use MessageScroller to scroll a message list with auto-anchoring.

## Registry install

```bash
pnpm dlx shadcn@latest add @tile-ui/message-scroller
```

## Package usage

```tsx
import { TMessageScroller } from '@tile-ui/vue';

<TMessageScroller>
	<TMessageScrollerViewport>
		<TMessageScrollerContent>
			<TMessageScrollerItem>Message one</TMessageScrollerItem>
		</TMessageScrollerContent>
	</TMessageScrollerViewport>
</TMessageScroller>
```

## Highlights

- Viewport and content
- Scroll anchor
- Scroll buttons
