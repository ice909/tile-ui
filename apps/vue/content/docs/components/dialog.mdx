> Use Dialog to require a decision before continuing.

## Registry install

```bash
pnpm dlx shadcn@latest add @tile-ui/dialog
```

## Package usage

```tsx
import { TDialog } from '@tile-ui/vue';

<TDialog>
	<TDialogTrigger>Open</TDialogTrigger>
	<TDialogContent>
		<TDialogHeader>
			<TDialogTitle>Edit profile</TDialogTitle>
			<TDialogDescription>Make changes to your profile.</TDialogDescription>
		</TDialogHeader>
		<TDialogFooter>
			<TButton>Save</TButton>
		</TDialogFooter>
	</TDialogContent>
</TDialog>
```

## Highlights

- Trigger, overlay, and content
- Header, footer, title, and description
- Close button
