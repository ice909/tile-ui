title: Checkbox
description: An accessible checkbox with indeterminate state.
---

> Use Checkbox for multi-select choices.

## Registry install

```bash
pnpm dlx shadcn@latest add @tile-ui/checkbox
```

## Package usage

```tsx
import { TCheckbox } from '@tile-ui/vue';

<TCheckbox />
```

## Highlights

- Indeterminate state support
- Accessible checkbox role
- Pairs with Field and Form

## Registry dependencies

| Item       | Purpose                            |
| ---------- | ---------------------------------- |
| `checkbox` | Component source and module styles |
