> Use Sidebar to add a collapsible application sidebar.

## Registry install

```bash
pnpm dlx shadcn@latest add @tile-ui/sidebar
```

## Package usage

```tsx
import { TSidebar } from '@tile-ui/vue';

<TSidebarProvider>
	<TSidebar>
		<TSidebarContent>
			<TSidebarGroup>
				<TSidebarGroupLabel>Menu</TSidebarGroupLabel>
			</TSidebarGroup>
		</TSidebarContent>
	</TSidebar>
	<TSidebarTrigger />
</TSidebarProvider>
```

## Highlights

- Provider and trigger
- Variants and sides
- Collapsible modes

## Registry dependencies

| Item      | Purpose                            |
| --------- | ---------------------------------- |
| `sidebar` | Component source and module styles |
| `core`    | Framework-agnostic logic helpers   |
| `styles`  | Shared SCSS tokens and globals     |

## API reference

### Sidebar

| Prop          | Type                                 | Default |
| ------------- | ------------------------------------ | ------- |
| `side`        | `'left' \| 'right'`                  | —       |
| `variant`     | `'sidebar' \| 'floating' \| 'inset'` | —       |
| `collapsible` | `'offcanvas' \| 'icon' \| 'none'`    | —       |

### SidebarProvider

| Prop           | Type                      | Default |
| -------------- | ------------------------- | ------- |
| `defaultOpen`  | `boolean`                 | —       |
| `open`         | `boolean`                 | —       |
| `onOpenChange` | `(open: boolean) => void` | —       |
