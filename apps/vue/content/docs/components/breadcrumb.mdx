> Use Breadcrumb to show the current location in a hierarchy.

## Registry install

```bash
pnpm dlx shadcn@latest add @tile-ui/breadcrumb
```

## Package usage

```tsx
import { TBreadcrumb, TBreadcrumbList, TBreadcrumbItem, TBreadcrumbLink, TBreadcrumbSeparator, TBreadcrumbPage } from '@tile-ui/vue';

<TBreadcrumb>
	<TBreadcrumbList>
		<TBreadcrumbItem>
			<TBreadcrumbLink href="/docs">Docs</TBreadcrumbLink>
		</TBreadcrumbItem>
		<TBreadcrumbSeparator />
		<TBreadcrumbItem>
			<TBreadcrumbPage>Button</TBreadcrumbPage>
		</TBreadcrumbItem>
	</TBreadcrumbList>
</TBreadcrumb>
```

## Highlights

- List, item, link, and page
- Separator and ellipsis
- `asChild` on links

## Registry dependencies

| Item         | Purpose                            |
| ------------ | ---------------------------------- |
| `breadcrumb` | Component source and module styles |
