> Use Sheet to slide a panel from the edge of the screen.

## Registry install

```bash
pnpm dlx shadcn@latest add @tile-ui/sheet
```

## Package usage

```tsx
import { TSheet, TSheetTrigger, TSheetContent, TSheetTitle, TSheetDescription } from '@tile-ui/vue';

<TSheet>
	<TSheetTrigger>Open</TSheetTrigger>
	<TSheetContent side="right">
		<TSheetTitle>Details</TSheetTitle>
		<TSheetDescription>Supporting details.</TSheetDescription>
	</TSheetContent>
</TSheet>
```

## Highlights

- Four sides
- Trigger, overlay, and content
- Header, footer, title, and description
