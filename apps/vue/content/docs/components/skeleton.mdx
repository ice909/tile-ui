---
title: Skeleton
description: A loading placeholder that mirrors the shape of the content it replaces.
---

> Use Skeleton to reserve layout space while content loads.

## Registry install

```bash
pnpm dlx shadcn@latest add @tile-ui/skeleton
```

## Package usage

```tsx
import { TSkeleton } from '@tile-ui/vue';

<TSkeleton />
```

## Highlights

- Pulse animation
- Sizes to its container
- Composes inside Card and Table

## Registry dependencies

| Item       | Purpose                            |
| ---------- | ---------------------------------- |
| `skeleton` | Component source and module styles |
| `core`     | Framework-agnostic logic helpers   |
| `styles`   | Shared SCSS tokens and globals     |

## API reference

### Skeleton

No custom props.
