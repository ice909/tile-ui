title: NavigationMenu

---

> Use NavigationMenu for primary site or app navigation.

## Registry install

```bash
pnpm dlx shadcn@latest add @tile-ui/navigation-menu
```

## Package usage

```tsx
import { TNavigationMenu, TNavigationMenuList, TNavigationMenuItem, TNavigationMenuTrigger, TNavigationMenuContent } from '@tile-ui/vue';

<TNavigationMenu>
	<TNavigationMenuList>
		<TNavigationMenuItem value="docs">
			<TNavigationMenuTrigger>Docs</TNavigationMenuTrigger>
			<TNavigationMenuContent>Documentation links.</TNavigationMenuContent>
		</TNavigationMenuItem>
	</TNavigationMenuList>
</TNavigationMenu>
```

## Highlights

- Viewport mode
- Item, trigger, and content
- Link with active state

## Registry dependencies

| Item              | Purpose                            |
