title: NavigationMenu
description: Navigation menu with viewport.
---

> Use NavigationMenu for primary site or app navigation.

## Registry install

```bash
pnpm dlx shadcn@latest add @tile-ui/navigation-menu
```

## Package usage

```tsx
import { NavigationMenu, NavigationMenuList, NavigationMenuItem, NavigationMenuTrigger, NavigationMenuContent } from '@tile-ui/vue';

<NavigationMenu>
	<NavigationMenuList>
		<NavigationMenuItem value="docs">
			<NavigationMenuTrigger>Docs</NavigationMenuTrigger>
			<NavigationMenuContent>Documentation links.</NavigationMenuContent>
		</NavigationMenuItem>
	</NavigationMenuList>
</NavigationMenu>
```

## Highlights

- Viewport mode
- Item, trigger, and content
- Link with active state

## Registry dependencies

| Item              | Purpose                            |
