title: ButtonGroup
description: Grouped button container.
---

> Use ButtonGroup to attach related buttons into a single control.

## Registry install

```bash
pnpm dlx shadcn@latest add @tile-ui/button-group
```

## Package usage

```tsx
import { TButtonGroup } from '@tile-ui/vue';

<TButtonGroup>
	<TButton>One</TButton>
	<TButton>Two</TButton>
	<TButton>Three</TButton>
</TButtonGroup>
```

## Highlights

- Three variants
- Four sizes
- Text and separator

## Registry dependencies

| Item           | Purpose                            |
| -------------- | ---------------------------------- |
| `button-group` | Component source and module styles |
| `core`         | Framework-agnostic logic helpers   |
| `styles`       | Shared SCSS tokens and globals     |

## API reference

### ButtonGroup

| Prop      | Type                                  | Default |
| --------- | ------------------------------------- | ------- |
| `variant` | `'default' \| 'outline' \| 'ghost'`   | —       |
| `size`    | `'default' \| 'sm' \| 'lg' \| 'icon'` | —       |
| `asChild` | `boolean`                             | —       |

### ButtonGroupText

| Prop      | Type      | Default |
| --------- | --------- | ------- |
| `asChild` | `boolean` | —       |

### ButtonGroupSeparator

No custom props.
