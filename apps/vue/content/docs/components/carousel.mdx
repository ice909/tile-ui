> Use Carousel to cycle through a set of items.

## Registry install

```bash
pnpm dlx shadcn@latest add @tile-ui/carousel
```

## Package usage

```tsx
import { Carousel, CarouselContent, CarouselItem, CarouselPrevious, CarouselNext } from '@tile-ui/vue';

<Carousel>
	<CarouselContent>
		<CarouselItem>Slide one</CarouselItem>
		<CarouselItem>Slide two</CarouselItem>
	</CarouselContent>
	<CarouselPrevious />
	<CarouselNext />
</Carousel>
```

## Highlights

- Horizontal and vertical
- Content, item, previous, and next

## Registry dependencies

| Item       | Purpose                            |
| ---------- | ---------------------------------- |
| `carousel` | Component source and module styles |
| `core`     | Framework-agnostic logic helpers   |
| `styles`   | Shared SCSS tokens and globals     |

## API reference

### Carousel

| Prop          | Type                         | Default      |
| ------------- | ---------------------------- | ------------ |
| `orientation` | `'horizontal' \| 'vertical'` | 'horizontal' |
